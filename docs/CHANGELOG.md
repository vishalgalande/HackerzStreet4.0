## How to Use This File

1. **Before you commit**, add a row to your section describing what you changed.
2. Keep each entry on a **single line** (file path + short description).
3. When your branch is **merged to main**, move your entries under a new version heading:
   ```
   ## [v0.1.0] — YYYY-MM-DD
   ### Features
   - Description (#PR)
   ```
4. **Never edit another teammate's section** — this prevents merge conflicts.
